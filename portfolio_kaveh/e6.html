Projet Promex

PME de distribution B2B (42 salariés, 4,2 M€ CA) basée à Villejuif. Mission : remplacer des fichiers Excel partagés par deux applications métier complémentaires partageant la même base de données promex_db.

🏢 Contexte & Problématique

PROMEX gérait ses stocks et commandes via des fichiers Excel partagés sur un réseau local, générant :

  • Aucune base de données centralisée — doublons et pertes
  • Zéro contrôle d'accès ni traçabilité des modifications
  • Stocks inaccessibles à distance pour les commerciaux terrain
  • Saisie des commandes fournisseurs 100% manuelle
  • Aucun historique des mouvements de stock

🎯 Solution développée

Deux applications métier complémentaires sur une base MySQL partagée :

  • SP1 · WebStock — Gestion des stocks via navigateur (client léger PHP)
  • SP2 · LogiDesk — Gestion des commandes fournisseurs depuis les postes achat (client lourd Python)
  • Architecture MVC sur les deux projets
  • Planning de développement : sept. 2025 → mai 2026
  • Livrables : CDC, MCD/MLD, UML, code source, jeux d'essai

Développement

Situations professionnelles.

SP1
Client Léger · Web · PHP
WebStock
Contexte

Application web accessible depuis tout navigateur, sans installation. Permet aux commerciaux et administrateurs de PROMEX de gérer le stock en temps réel depuis n'importe quel poste du réseau interne.

Fonctionnalités
  • Authentification avec gestion des rôles (Commercial / Administrateur)
  • CRUD complet sur les produits et catégories
  • Enregistrement des mouvements de stock (entrées/sorties) avec motif
  • Recherche et filtrage des produits par désignation ou catégorie
  • Gestion des utilisateurs réservée à l'administrateur
Architecture MVC
  • Modèles — classes PHP, accès BDD via PDO préparé
  • Vues — fichiers PHP générant le HTML
  • Contrôleurs — logique métier et routage
  • Database — Singleton PDO, instance unique
Stack technique
PHP 8.x HTML5/CSS3 MySQL 8.0 PDO Apache/XAMPP MVC Git

SP2
Client Lourd · Desktop · Python
LogiDesk
Contexte

Application desktop installée sur les postes du service achat. Centralise la gestion des commandes fournisseurs en s'appuyant sur la même base MySQL que WebStock pour garantir la cohérence des données à l'échelle de l'entreprise.

Fonctionnalités
  • Authentification avec gestion des rôles (Acheteur / Administrateur)
  • CRUD complet sur les fournisseurs
  • Création et suivi des commandes fournisseurs
  • Gestion des lignes de commande (ajout / suppression)
  • Modification du statut (En cours / Validée / Livrée)
  • Tableau de bord des commandes en cours
  • Gestion des utilisateurs réservée à l'administrateur
Architecture MVC + PySide6
  • Modèles — classes Python, accès BDD via mysql-connector
  • Vues — classes PySide6 (interface graphique Qt)
  • Contrôleurs — logique métier entre modèles et vues
  • Signaux/Slots — communication événementielle Qt
  • Database — Singleton MySQL, instance unique
Stack technique
Python 3.12 PySide6 MySQL 8.0 mysql-connector MVC VS Code Git
